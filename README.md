# เดินเล่นเชียงคาน

แอปหน้าเดียวสำหรับทริปเชียงคาน 10–12 พ.ย. ไม่ต้อง build

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | โครงหน้าเว็บ |
| `css/style.css` | สีและหน้าตาทั้งหมด |
| `js/config.js` | Google Maps API key |
| `js/data.js` | ที่พัก ตารางเวลา และจุดแวะ (แก้แผนเที่ยวที่นี่) |
| `js/icons.js` | ไอคอนและสีของแต่ละหมวด |
| `js/app.js` | การทำงานของแอป |
| `docs/chiangKhan.md` | ข้อความจากหน้าเว็บ |
| `archive/walking.original.html` | ไฟล์เดิมก่อนแยก (ลบได้เมื่อไม่ต้องใช้แล้ว) |

## เปิดใช้งาน

ดับเบิลคลิก `index.html` ได้เลย ถ้าใส่ API key ที่จำกัดโดเมนไว้แล้ว ให้เปิดผ่านเซิร์ฟเวอร์แทน เพราะ Google ตรวจโดเมนของหน้าเว็บ:

```
python -m http.server 8000
```

แล้วเปิด <http://localhost:8000>

## เปิดแผนที่จริงและ Street View ในแอป

ปุ่ม "นำทาง" "ดูรูป & รีวิว" และ "Street View" ใช้ได้โดยไม่ต้องมี key ส่วนแท็บแผนที่ในแอปต้องใช้ key ของ Maps Embed API ซึ่ง Google ไม่คิดค่าใช้งาน

1. เปิด [Google Cloud Console](https://console.cloud.google.com/) แล้วสร้างโปรเจกต์ (Google อาจให้ผูกบัญชีเรียกเก็บเงิน)
2. เปิดใช้ **Maps Embed API**
3. สร้าง API key ในหน้า Credentials
4. จำกัด key นี้ให้ใช้ได้เฉพาะ Maps Embed API และเฉพาะโดเมนของเว็บ เช่น `localhost:8000/*`
5. วาง key ใน `js/config.js`

key จะมองเห็นได้ในซอร์สของหน้าเว็บ จึงควรจำกัดตามข้อ 4 ทุกครั้ง
